# Catechism Search

A Python-based text search tool for querying catechism documents.

## Motivation
This project explores lightweight text search over structured religious texts.

## Data
Raw text files are stored externally.
Processed versions are generated via `src/preprocess.py`.

## How to Run
pip install -r requirements.txt
python src/preprocess.py
python src/search.py
